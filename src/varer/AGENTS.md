- Oppskriftskoblingen (`product_recipe_links`) skrives bare via `recipeLinkWrite.ts`: én betinget UPDATE/DELETE med id+product_id+recipe_id+rå `updated_at`+nøyaktige innstillinger (null via `is`), og nøyaktig én returnert rad er eneste suksess; salgsenhetskladden eier sin aksepterte basis. Why: oppdatering på bare id lot en gammel kladd skrive over en ny oppskrift.
- Godkjent deklarasjonsversjon (`recipe_declaration_versions` via `products.declaration_version_id`) er publisert fasit til ny eksplisitt godkjenning; `declaration_needs_review`/utdatert beregning gir bare «Krever gjennomgang» (status `stale`, inkludert i «Godkjent»-filteret via `matchesLabelingFilter`), og eksporten (`exportDecision`/`approvedContent`) holder review-felt utenfor `content_hash`. Beregningssynk skriver aldri over et publisert snapshot. Why: review-flagget fjernet tidligere godkjente varer fra lister og kundeeksport (20→8).
- Etikett/forhåndsvisning/utskrift bruker sist godkjente versjon som standard (`approvedLabel.ts`); ny beregning vises bare som merket kladd, og kladden holdes montert for pliktfeltsjekken før godkjenning. NULL i godkjent versjon er autoritativt. Why: forhåndsvisning og utskrift viste løpende beregning som om den var godkjent.
- Recipe page (`/varer/oppskrifter/:id`): tabs live in `lib/recipeTabs.ts` and switch via `useRecipeTab` (`history.replaceState`, buttons, not links); «Gjenstår» is composed only in `lib/recipeRemaining.ts` from existing results, label issues share `lib/recipeLabelIssues.ts` with `ConsumerLabelSection`, and product links/insert/delete live only in `hooks/useRecipeProductLinks.ts`. Why: router navigation or anchors tripped the unsaved-changes guard, and duplicated checklist/link logic drifts.
- Merkefanen (`LabelTab`) er én side uten underfaner: data/godkjenningssperrer i `hooks/useLabelTabData.ts`, sperrer per kilde i `lib/labelApproveIssues.ts`, allergenkontroll av manuell tekst bare i `lib/manualAllergenCheck.ts` (feil = sperre, usikkert = «Bør sjekkes»), pliktfeltrader fra `buildLabelChecklist` via `lib/labelFieldRows.ts`, merkesperrer i `lib/labelClaims.ts`; nettovekt per vare skrives bare via `conditionalLinkUpdate`. Why: to sjekklister og kopierte låseregler drev fra hverandre, og godkjenning skal sperres likt som «Gjenstår».
